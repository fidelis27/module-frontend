# Repository agent instructions

## Documentation

- Before creating a Markdown file, find and update the existing document.
- Create a document only when it fits the taxonomy in `docs/README.md`; add it to the index in the same commit.
- Record architecture decisions as numbered ADRs and link related decisions.
- Do not add plan, task, notes, draft, learnings, or prompt files to the repository; put proposals in the PR description or an issue.
- Do not duplicate documentation; link to the canonical source.
- Avoid counts, sizes, versions, and status dates that age; link to a reproducible source instead.
- Run `npm run check:docs` before committing documentation changes.
