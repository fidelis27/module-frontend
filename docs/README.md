## Architecture and decisions

The [ADR index](./adr/README.md) lists accepted architecture decisions.
Relevant to the event bus: [ADR 0006](./adr/0006-event-bus.md) describes its
typed API and delivery semantics, and [ADR 0007](./adr/0007-bus-global-state.md)
describes its versioned page-wide state.

## How to maintain this documentation

Update the existing document before creating one. New active documents must
fit this index; record architecture decisions as numbered ADRs. Keep both
READMEs aligned and avoid duplicated content.
